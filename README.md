Sales Prediction Using Machine Learning

About the Project

This project predicts sales using machine learning techniques based on advertising data.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

Project Files

- "app.py" - Main application
- "train_model.py" - Model training
- "sales_model.pkl" - Trained machine learning model
- "Advertising.csv" - Dataset
- "pyvenv.cfg" - Python environment configuration

How to Run

1. Install Python on your system.
2. Install the required Python libraries.
3. Run the application using the appropriate command.
